# 段階0 計測シート

iPhone で一日録り続けられるかを確かめる（`concept.md` の「10. MVP と段階」と「13. 最初の一歩」の 6・8）。ここが駄目なら文字起こしより前に設計を変える。結果はこのシートに書き込む。

## 準備
- [ ] `scripts/reinstall.sh` で iPhone に入れる。初めてなら iPhone の 設定 > 一般 > VPNとデバイス管理 で開発者を「信頼」する。
- [ ] 前の晩に 100% まで充電する。低電力モードはオフ（比べられるように）。
- [ ] 初めて「開始」を押すとマイクの許可が出るので「許可」。

## アプリの見方
| 場所 | わかること |
| --- | --- |
| 画面の「今の状態」 | 経過時間、**録れた時間**（経過時間より短ければ、その差だけどこかで止まっていた）、ファイル数と容量、残り容量、中断の回数、バッテリー、使っているマイク |
| 画面の「記録」 | 開始・停止・中断・再開・1時間ごとのバッテリー。停止ボタンなしで終わった（強制終了・クラッシュ）ときは、次に開いたとき「最後に録音が動いていたのは …」が出る |
| 「ファイル」アプリ > この iPhone 内 > あとろく > 記録.txt | 上の記録の全部。アプリが落ちても残る |
| 「ファイル」アプリ > この iPhone 内 > あとろく > RingBuffer | 1分ごとの音声（`20261020-091502.m4a` = 書き始めの時刻）。直近30分と1ファイル分だけ残り、古いものは録音中に消える。停止しているあいだは消えない |

音声はバックアップ（iCloud・パソコン）から外してあり、iPhone の外には出ない。

## 1. 一日の連続録音（8時間）
朝に前面で「開始」→ ロックしてポケットへ → いつもどおり過ごす（通話・音楽・動画もふだんどおり）→ 夕方にアプリを開いて記録を見る →「停止」。

| 項目 | 結果 |
| --- | --- |
| 日付 | |
| 開始の時刻とバッテリー | |
| 停止の時刻とバッテリー | |
| 経過時間 / 録れた時間 | |
| 減ったバッテリー（%）と、1時間あたり | |
| 設定 > バッテリー でのあとろくの割合 | |
| 止まった時刻（あれば）と理由（記録の文） | |
| 中断の回数と、そのたびに再開したか | |
| 本体が熱くなったか | |
| ファイル数・容量が増え続けていないか（31〜32個、約7〜8MB で止まるはず） | |

目安: 一晩録音するほかのアプリで 10〜14% という例がある（`concept.md` 6）。

## 2. 通話などのあとの再開
アプリを裏に回して録音中に、それぞれ試す。記録に「中断された」→「中断が終わった」→「再開した」と並べば OK。

| 場面 | 再開したか | 記録の文・メモ |
| --- | --- | --- |
| 電話がかかってきて、出て、話して切る | | |
| 電話がかかってきて、出ずに切る（呼び出し音だけなら止まらない設定） | | |
| 自分から電話をかけて切る | | |
| LINE などのアプリの通話 | | |
| ボイスメモで録音して止める | | |
| カメラで動画を撮る | | |
| Siri を呼ぶ | | |
| 録音中にアプリの切り替え画面で上にはじく（強制終了。再開しないのが正しい。次に開いたとき記録に残るか） | | |

## 3. ほかの操作への影響
| 確かめること | 結果 |
| --- | --- |
| 音楽・動画が止まらず、ふつうの音量でスピーカーから鳴る | |

| イヤホンをつないでも画面の「マイク」が iPhone 本体のまま | |

## 4. 置き場所による拾い方
同じ会話（または同じ文章の読み上げ、同じ動画の音）を、置き場所を変えて各2〜3分ずつ録る。止めてから「ファイル」アプリの RingBuffer で、その時刻のファイルを聞き比べる。30分より古いファイルは次の録音中に消えるので、続けて録ってすぐ聞くか、残したいファイルを RingBuffer の外（この iPhone 内の別のフォルダ）にコピーしておく。
