# あとろく（atoroku）

仕事中の会話を「録音ボタンを押し忘れても」残せる iPhone + Apple Watch アプリ。

- **さかのぼり録音**: iPhone が直近30分（設定で可変）の音声を持ち続け、Watch を1回タップすると「押す前の30分」ごと保存される。ドライブレコーダーと同じ考え方。
- **端末内で文字起こし**: 保存した音声は iOS 26 の SpeechAnalyzer で端末の中で日本語の文字になる。音声は一定期間（初期値30日）端末内に残り、崩れた箇所を聞き直せる。
- **Claude で整理**: 文字だけを自分の API キーで Claude に送り、「件名・決まったこと・頼まれたこと・自分の宿題・用語」に整える。あとから日付や相手で探せる。
- **音声は iPhone から出ない**: クラウドに上がるのは文字だけ。サーバーは持たない。

## 状態
段階0（一日録り続けられるかの計測）の前。計画は [docs/concept.md](docs/concept.md)、開発環境の用意は [docs/setup.md](docs/setup.md)。

## 対象
- iPhone 17（iOS 26）、Apple Watch Series 5（watchOS 10）
- Swift / SwiftUI、Xcode 27、無料の Apple ID（Personal Team）で自分の端末にインストールして使う

## 注意
録音は参加している会話に限り、勤務先のルールを確認してから使うこと。残すと決めたときは相手に一言伝える。
